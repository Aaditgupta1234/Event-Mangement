# 🎬 Reel Effects - Quick Reference

## 🎨 Effects at a Glance

### Transitions (How photos change)

| Effect      | Icon | Best For           | Speed  |
| ----------- | ---- | ------------------ | ------ |
| Fade        | 📀   | Classic, timeless  | Medium |
| Slide Left  | →    | Dynamic, flowing   | Medium |
| Slide Right | ←    | Emphasis, action   | Medium |
| Zoom        | 🔍   | Focusing, dramatic | Fast   |
| Rotate      | ⟳    | Fun, playful       | Fast   |
| Blur        | 💨   | Artistic, dreamy   | Slow   |

### Filters (Color & tone)

| Filter      | Icon | Mood             | Use Case                |
| ----------- | ---- | ---------------- | ----------------------- |
| None        | ✓    | Modern, clean    | Bright, colorful photos |
| Sepia       | 📷   | Nostalgic, warm  | Throwback, memories     |
| Vintage     | ✨   | Classic, elegant | Formal, professional    |
| Vibrant     | 🌈   | Fun, energetic   | Parties, celebrations   |
| Cool Blue   | ❄️   | Calm, peaceful   | Nature, meditation      |
| Warm Orange | 🔥   | Cozy, intimate   | Sunset, indoor moments  |

### Text Styles (Title appearance)

| Style  | Color  | Effect            | Vibe         |
| ------ | ------ | ----------------- | ------------ |
| Modern | White  | Subtle shadow     | Professional |
| Retro  | Yellow | Bold black shadow | Vintage      |
| Neon   | Cyan   | Glowing effect    | Energetic    |
| Shadow | White  | Deep shadow       | Cinematic    |

### Music Themes

| Option    | Mood     | Energy    | Best For       |
| --------- | -------- | --------- | -------------- |
| None      | Silent   | –         | Nature shots   |
| Upbeat    | Happy    | High      | Celebrations   |
| Calm      | Peaceful | Low       | Relaxation     |
| Energetic | Dynamic  | Very High | Action, sports |

### Duration Guide

- **1-2s** - Fast-paced, music videos, action
- **2-3s** - Balanced, most common choice
- **3-4s** - Scenic, landscape, letting each image breathe
- **4-5s+** - Emotional, contemplative reels

## ⚡ Pro Tips

✓ **Match transition speed to music tempo**  
✓ **Use same duration for consistent pacing**  
✓ **Combine complementary filters**  
✓ **Order photos for best story flow**  
✓ **Test preview before downloading**  
✓ **Shorter reels load faster**  
✓ **Avoid extreme transitions with static scenes**  
✓ **Neon style works best on dark backgrounds**

## 🎮 Quick Steps

1. **Upload** - Click "Add Memory" (JPG, PNG, WebP ≤5MB)
2. **Select** - Choose minimum 2 photos
3. **Title** - Enter your reel name
4. **Effects** - Set transition, duration, filter, music, text style
5. **Preview** - Check effects summary
6. **Create** - Generate video
7. **Download** - Save & share! 📥

_Adds depth & focus_

_Fun & playful_

## ❓ Troubleshooting

**Q: Effect not showing?**  
A: Reload page, clear cache, try different browser

**Q: Video too large?**  
A: Reduce image count or duration

**Q: Text unreadable?**  
A: Try different text style, shorter title

**Q: Video won't download?**  
A: Check browser permissions, try Chrome/Edge

**Q: What format do I need?**  
A: JPG, PNG, or WebP - all work! Max 5MB per photo
